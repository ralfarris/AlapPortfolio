# AlphaSolace Portfolio

Single-page portfolio for Mini Web Apps, Short-Form Video Editing, Virtual Assistance, and Manual Game Piloting (Honkai: Star Rail & Wuthering Waves).

## Setup
1. Open `script.js` and set `githubUsername` in `SITE_CONFIG`.
2. Preview locally by opening `index.html` in a browser.

## Deploy Free on GitHub Pages
1. Create a public repo named `<your-github-username>.github.io` (or any repo name).
2. Push `index.html`, `styles.css`, and `script.js` to the `main` branch.
3. In GitHub: **Settings → Pages → Source: Deploy from a branch (`main` / `/ (root)`)**.
4. Wait ~1 minute and your portfolio URL is live.
